# Linux QM-Utils library

## Recipes

`Recipes` files contain commands you will often use to build, test or deploy.
They are actually `Makefiles`, you can read them, or use make to run commands.

To get usage information, run:

```
make -f Recipes help
```

If there is no Recipes file, you may get help from a Makefile:

```
make help
```

You can also read `.gitlab-ci.yml` to know how the CI builds and runs tests.
