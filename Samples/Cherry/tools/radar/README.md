The Python scripts in this directory need the following additional Python packages:
  - numpy
  - matplotlib
  - superqt
  - pyqtgraph
  - PyQt5

If you use a custom Python environment like `venv` or `conda`:

```
pip install numpy
pip install matplotlib
pip install superqt
pip install pyqtgraph
pip install PyQt5
```

If you use system wide Python packages:

```
sudo apt-get install python3-numpy
sudo apt-get install python3-matplotlib
sudo apt-get install python3-superqt
sudo apt-get install python3-pyqtgraph
sudo apt-get install python3-pyqt5
```
