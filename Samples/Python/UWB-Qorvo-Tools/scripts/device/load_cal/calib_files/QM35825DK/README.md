# QM35825DK

This directory contains default calibration and configuration JSON files for the `QM35825DK` kit.

- **jolie_omni_jolie_aoa_jolie_omni.json** expects to have connected:
  * Jolie 1 (omni) on ANT1 port
  * Jolie 3 (directional PDoA antenna) on ANT2 and ANT3 ports
  * Jolie 1 (omni) on ANT4 ports
